### Leveraging Markov Logic Chains for energetic renovation suggestions

This repository contains the code, dataset and results of the paper 'Leveraging Markov Logic Chains for energetic renovation suggestions', submitted to the International Conference on Sustainability in Energy and Buildings (SEB-26).

Only a subset of the data is made available due to confidentiality reasons, but the reported results stem from the full dataset.
